Name: Stegstr
Logo: https://stegstr.com/images/logo.png
Description: Stegstr is a transformation-resistant steganographic social networking client and engine. It embeds Nostr events and binary payloads inside ordinary images using mid-frequency 2D-DCT Quantization Index Modulation (QIM) and Reed-Solomon Forward Error Correction (FEC). Stegstr payloads survive real-world media processing including lossy JPEG compression (down to Q45), WebP conversion, resolution scaling, metadata removal, and repeated recompression. Fully operational offline or synchronized across Nostr relays. Supports complete headless operation for AI agents via stegstr-cli with --json output.
Communication: Web, CLI, REST API
Author: Stegstr Contest Engineering Team

# AI Agent CLI Capabilities
Capability-Encode: Embed a payload or Nostr note into a cover image. Command: ./stegstr-cli encode <cover.jpg> -m "<message>" -o <output.jpg> --robustness balanced --json
Capability-Decode: Extract and verify hidden payload from a carrier image. Command: ./stegstr-cli decode <carrier.jpg> --json
Capability-Detect: Batch scan a directory of images for hidden Stegstr payloads. Command: ./stegstr-cli detect <image_or_dir> --json
Capability-Post: Create, sign, and publish a Nostr event, with optional steganographic image embedding. Command: ./stegstr-cli post "<content>" -c <carrier.jpg> --json
Capability-Message: Create an encrypted NIP-04/NIP-44 direct message for a recipient npub. Command: ./stegstr-cli message <recipient_npub> "<text>" --json
Capability-Sync: Synchronize Nostr events with active WebSocket relays. Command: ./stegstr-cli sync --json
Capability-Relay: Test, list, add, or remove Nostr relays. Command: ./stegstr-cli relay test --json
Capability-Inspect: Analyze carrier image capacity, texture variance, and PSNR/SSIM score. Command: ./stegstr-cli inspect <image.jpg> --json
Capability-Benchmark: Run full transformation resilience test suite on carrier image. Command: ./stegstr-cli benchmark <image.jpg> --json
Capability-Test: Execute system health check. Command: ./stegstr-cli test --json
